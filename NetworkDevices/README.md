## Example Usage

```
# Find exposed Nessus scan reports
intitle:"Nessus Scan Report" "This file was generated by Nessus"

# Find Zabbix monitoring dashboards
inurl:zabbix.php AND intext:"Zabbix SIA"

# Find OWASP ZAP scan reports
intext:ZAP Scanning Report Summary of Alerts ext:html

# Find Cacti network graphing interfaces
inurl:"/cacti/graph_view.php" OR inurl:"/cacti/graph.php?"
```

## Why Network Device Discovery Matters

Exposed monitoring and network management tools reveal:

- **Vulnerability reports** expose known weaknesses with exact CVEs and remediation status
- **Monitoring dashboards** reveal internal network topology and host inventories
- **Traffic analysis** exposes bandwidth patterns and network utilization
- **Configuration files** may contain RADIUS secrets, SNMP communities, and admin passwords
